# Large coursework assets

These numbered parts preserve the selected SVM checkpoint and the full split table byte for byte. They are included in Git because the SVM checkpoint exceeds GitHub's individual file limit. Run `python tools/restore_repository_assets.py` from the project root after cloning. The command verifies each part and the reassembled SHA-256 before installing the original file. Normal-sized ANN checkpoints, complete experiment logs, raw VLM responses, sample data and the demonstration are tracked directly. Do not edit or reorder the parts.
